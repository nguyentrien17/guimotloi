Lưu ý kiến trúc an toàn: Trong ứng dụng web tĩnh chỉ sử dụng JavaScript phía client và file XML, trình duyệt không thể tự cung cấp cơ chế phân quyền bảo mật tuyệt đối hay ghi trực tiếp vào đĩa cứng máy chủ. Để đảm bảo an toàn tuyệt đối khi đưa lên Internet, hệ thống đã được phân tách hoàn toàn theo chuẩn AdminRepository với hợp đồng API RESTful sau:

POST /api/admin/auth/login — Xác thực danh tính quản trị viên & cấp JWT Bearer Token
GET /api/admin/stats — Trả về số liệu thống kê thực tế được tính toán từ cơ sở dữ liệu
GET /api/admin/messages — Truy vấn danh sách thư có kiểm tra quyền, phân trang và tìm kiếm
PATCH /api/admin/messages/:id/status — Ẩn/hiện/chờ duyệt thư kèm lý do và ghi nhận audit log
DELETE /api/admin/messages/:id — Xóa mềm hoặc xóa vĩnh viễn thư khỏi cơ sở dữ liệu
POST /api/admin/messages/batch — Thực hiện thao tác hàng loạt có kiểm soát quyền hạn
